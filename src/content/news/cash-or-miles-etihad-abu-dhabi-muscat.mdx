## Which fare should you compare?

The cheapest cash option did not include a checked bag, so we used the cash
Value fare instead. If you would actually travel with cabin baggage only,
price the cheaper fare in the [Cash or Miles calculator](/calculator/cash-or-miles/)
before using miles. And if you might change the flight, read both sets of
rules first: the reward had a higher change fee and did not allow changes
close to departure.
