Start with the company named on your booking receipt. If a comparison site sent you somewhere else to pay, check the confirmation for the actual seller. [Etihad](https://www.etihad.com/en-ae/help/faq/manage) directs passengers who booked through an agent back to that agent for changes and refunds. [flydubai](https://www.flydubai.com/en/book-and-manage/view-or-change-booking/) lets you view an agent booking and add some extras online, but directs you to the agent for other changes. [Emirates](https://www.emirates.com/ae/english/help/forms/refund-request/) directs you to the travel agent for a refund on an agency-issued ticket. Extras bought directly from Emirates can be a separate request under their own terms.

Before you pay, compare the same flight and fare with the airline. Ask the seller who handles a change, what its own fees are and when you need to act. Before you cancel, ask for a written breakdown of what you’d get back, how it would be returned and whether the change affects anyone else on the booking. If you want new dates, ask for the whole price to change, including any fare difference. Keep the seller’s order number and the airline booking reference.

Treat ‘Cancel’ and ‘Request a refund’ as actions, not price checks. Emirates warns that submitting its ticket refund request cancels the booking and can’t be undone. If you only need a quote, ask without authorising a change.
